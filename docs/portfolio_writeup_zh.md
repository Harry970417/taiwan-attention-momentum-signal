# 作品集寫作:注意力遇上動能

## 研究緣起

這個專案的起點是一個在美股文獻中已有實證支持、但在台股缺乏公開可重現
研究的問題:Google 搜尋量異常上升,是否能作為投資人注意力的代理變數,
進而預測個股短期報酬?台股散戶比重高、題材輪動快,直覺上應該是一個
適合檢驗這個假設的市場,但我在文獻回顧階段沒有找到針對台股的對應研究,
於是決定自己動手,從資料蒐集到統計檢定完整跑一輪。

## 研究設計與資料工程

我以台股 50 檔大型權值股(以 0050 成分股為主,涵蓋半導體、金融、航運、
電信等產業)為樣本,時間為 2021 年 6 月至 2026 年 6-7 月,經 rolling
window 與資料對齊後形成 237 週有效樣本。資料完全來自真實公開來源:
用 `pytrends` 抓取週度 Google 搜尋量指數,用 FinMind 的公開 REST API
抓取日收盤價與三大法人買賣超(外資、投信、自營商分開列示)。這個過程
本身就有不少值得記錄的工程問題——例如 Google Trends 對不同關鍵字的
查詢結果各自正規化到 0–100 的尺度,不同股票之間無法直接比較原始數值,
我用「錨點關鍵字」批次查詢的方式做近似校正;又例如 FinMind 的官方
Python 套件在較新版本的 Python 環境下有相依性衝突無法安裝,我改為
直接呼叫其公開 REST API 繞過這個問題。這些看似瑣碎的細節,其實反映了
真實世界資料研究中經常遇到的狀況——資料不會乾淨地躺在那裡等你分析,
取得乾淨、可信、可重現的資料本身就是研究的一部分。

## 從天真的正向結果,到主動尋找反證

用搜尋量建立「注意力衝擊」因子(相對自身歷史 52 週的 z-score 與比值)
後,第一輪的事件研究與截面分析(v0.2)都得到統計上顯著的正向結果:
8 週累積異常報酬(CAAR)達 +14.2%(t=8.46);週度截面 IC 為正且統計
顯著,ICIR 約 0.31,t 值約 4.8。如果研究到這裡就停下來,這會是一個
看起來很不錯、可以直接寫成「發現一個新因子」的故事。但我選擇沒有停在
這裡,而是主動設計檢定去嘗試推翻這個結果。

第一個懷疑是動能(v0.3):搜尋量上升的股票,會不會只是因為股價已經在
漲,才被更多人注意到、搜尋?以過去 4 週報酬做雙重排序(double sort)後,
答案部分證實了這個懷疑——效應幾乎完全集中在「過去已經上漲」的股票上,
過去贏家組 CAR 達 +30.8%(t=12.6),過去非贏家組僅 -1.1% 且不顯著。
進一步用 Fama-MacBeth 週度截面迴歸控制動能後,注意力因子的係數縮小了
約三分之一(約 36%),但仍顯著(p<0.001);用配對樣本法(matched
sample,找動能、成交量、波動度都相似的股票做對照組)比較後,注意力
事件股票仍然顯著優於對照組,1 週至 4 週優勢由 +1.7% 擴大至 +3.7%
(皆 p<0.0001),且優勢隨時間拉長而擴大。我也建構了正交化後的殘餘
注意力因子(residual attention factor),發現它在 1-2 週仍顯著
(IC=0.036/0.027,p<0.005),但到第 4 週已不顯著(IC=0.008,p=0.38)
——顯示注意力的獨立解釋力集中在極短窗口,且會隨動能訊號被稀釋。這些
證據拼湊出的圖像是:注意力效應與動能高度糾纏,但不是動能的簡單複製品。

第二個懷疑是法人籌碼(v0.4):台股的短期報酬經常受外資、投信買賣超
影響,如果法人資金流入同時解釋了股價上漲與散戶注意力上升,那麼前一步
觀察到的殘餘效應也可能只是法人籌碼的間接反映。我重新抓取三大法人
買賣超的機構別明細,把它加進迴歸模型與排序分析中檢驗。結果是清楚的
否定:注意力因子與各項法人買賣超指標的相關性都極低(最大 |r|=0.05,
遠低於動能的 0.28);加入法人籌碼控制後,Fama-MacBeth 迴歸中的注意力
係數僅收縮約 1%(0.00250→0.00247),與動能控制的 36% 收縮形成強烈
對比。三重排序(動能 × 注意力 × 法人流向)更直接顯示,在過去已上漲的
股票中,高注意力的效果不論法人是買超、中性還是賣超都同樣強勁(4 週
分別為 +2.51%、+4.45%、+2.99%)。法人籌碼被明確排除為這個效應的
替代解釋。

## 最終結論與研究態度

三輪檢定之後,我得到的結論是:Google Trends 搜尋量異常上升,在台股
大型股中會放大既有動能股票的短期續漲效果,但它不是一個能獨立於動能
存在的 alpha 因子,也不是法人籌碼的間接反映。這個結論沒有第一輪結果
那麼吸引人,但我認為它更有價值——因為它是經過主動、多角度嘗試推翻
之後仍然站得住腳的部分,而不是我最想聽到的答案。

我也刻意記錄了一個尚未完全解決的方法論張力:線性交互項(注意力×動能、
注意力×法人流向)在迴歸中並不顯著,這與雙重/三重排序呈現的強烈型態
有落差,較合理的解讀是真實的交互作用是門檻式、非線性的,而非能用
線性乘積捕捉——我選擇誠實記錄這個落差,而非略過不談。

需要特別說明的是,這個專案的產出是一組經過反覆驗證的統計證據,用來
回答「注意力訊號代表什麼」這個學術問題,不是一個可獲利的交易策略,
也不構成任何投資建議。我認為量化研究最重要的能力,不是找到一個看起來
顯著的結果,而是在承認一個結果之前,窮盡自己能想到的替代解釋去檢驗
它。這個專案完整保留了從天真結果到最終結論的修正過程(見 `reports/`
資料夾中三個版本的報告),我認為這個過程本身,比單一個「發現正向結果」
的故事更能展現我在資料工程、統計方法與研究誠信上的能力。
