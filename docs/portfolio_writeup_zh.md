# 作品集寫作:注意力遇上動能

## 研究緣起

這個專案的起點是一個在美股文獻中已有實證支持、但在台股缺乏公開可重現
研究的問題:Google 搜尋量異常上升,是否能作為投資人注意力的代理變數,
進而預測個股短期報酬?台股散戶比重高、題材輪動快,直覺上應該是一個
適合檢驗這個假設的市場,但我在文獻回顧階段沒有找到針對台股的對應研究,
於是決定自己動手,從資料蒐集到統計檢定完整跑一輪。

## 研究設計與資料工程

我以 50 檔台股大型權值股(以 0050 成分股為主,涵蓋半導體、金融、航運、
電信等產業)為樣本,建立了一條完整的資料管線:用 `pytrends` 抓取週度
Google 搜尋量指數,用 FinMind 的公開 REST API 抓取日收盤價與三大法人
買賣超。這個過程本身就有不少值得記錄的工程問題——例如 Google Trends
對不同關鍵字的查詢結果各自正規化到 0–100 的尺度,不同股票之間無法直接
比較原始數值,我用「錨點關鍵字」批次查詢的方式做近似校正;又例如
FinMind 的官方 Python 套件在較新版本的 Python 環境下有相依性衝突無法
安裝,我改為直接呼叫其公開 REST API 繞過這個問題。這些看似瑣碎的細節,
其實反映了真實世界資料研究中經常遇到的狀況——資料不會乾淨地躺在那裡
等你分析,取得乾淨、可信、可重現的資料本身就是研究的一部分。

## 從天真的正向結果,到主動尋找反證

用搜尋量建立「注意力衝擊」因子(相對自身歷史 52 週的 z-score 與比值)
後,第一輪的事件研究與截面 IC 分析都得到統計上顯著的正向結果:注意力
異常上升後,個股確實有較高的短期超額報酬。如果研究到這裡就停下來,
這會是一個看起來很不錯、可以直接寫成「發現一個新因子」的故事。但我選擇
沒有停在這裡,而是主動設計檢定去嘗試推翻這個結果。

第一個懷疑是動能:搜尋量上升的股票,會不會只是因為股價已經在漲,才被
更多人注意到、搜尋?用過去報酬把股票分組後,答案部分證實了這個懷疑——
效應幾乎完全集中在「過去已經上漲」的股票上,「過去未上漲」的股票沒有
統計上顯著的效應。進一步用 Fama-MacBeth 週度截面迴歸控制動能後,注意力
因子的係數縮小了約三分之一,但沒有完全消失;用配對樣本法(找動能、
成交量、波動度都相似的股票做對照組)比較後,注意力事件股票仍然顯著
優於對照組,而且這個優勢隨著時間拉長而擴大。這些證據拼湊出的圖像是:
注意力效應與動能高度糾纏,但不是動能的簡單複製品。

第二個懷疑是法人籌碼:台股的短期報酬經常受外資、投信買賣超影響,如果
法人資金流入同時解釋了股價上漲與散戶注意力上升,那麼前一步觀察到的
「殘餘效應」也可能只是法人籌碼的間接反映。我重新抓取三大法人買賣超的
機構別明細,把它加進迴歸模型與排序分析中檢驗。結果是清楚的否定:注意力
因子與法人買賣超幾乎沒有相關性,加入法人籌碼控制後,注意力因子的迴歸
係數幾乎沒有變化;三維排序更直接顯示,在過去已上漲的股票中,高注意力
的效果不論法人是買超還是賣超都同樣強勁。法人籌碼被明確排除為這個效應
的替代解釋。

## 最終結論與研究態度

三輪檢定之後,我得到的結論是:Google Trends 搜尋量異常上升,在台股大型
股中會放大既有動能股票的短期續漲效果,但它不是一個能獨立於動能存在的
alpha 因子。這個結論沒有第一輪結果那麼吸引人,但我認為它更有價值——
因為它是經過主動、多角度嘗試推翻之後仍然站得住腳的部分,而不是我最想
聽到的答案。

我認為量化研究最重要的能力,不是找到一個看起來顯著的結果,而是在承認
一個結果之前,窮盡自己能想到的替代解釋去檢驗它。這個專案完整保留了
從天真結果到最終結論的修正過程(見 `reports/` 資料夾中三個版本的報告),
我認為這個過程本身,比單一個「發現正向結果」的故事更能展現我在資料
工程、統計方法與研究誠信上的能力。
